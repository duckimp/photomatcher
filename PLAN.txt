Catatan Kritis & Potensi Edge Case
Agar aplikasi ini makin bulletproof saat digunakan, ada beberapa detail teknis dan potensi masalah yang perlu kamu atur logika code-nya dari awal:

1. Masalah "Off-by-One" / Geser Urutan (Efek Domino)

Masalah: Saat auto-fill, ternyata di tengah-tengah ada 1 foto yang terlewat (misal siswa B tidak foto), sehingga 20 siswa di bawahnya jadi geser salah semua.

Solusi: Buat fitur "Insert Blank / Shift Down" di tabel. Jika ada urutan yang geser, kamu tinggal klik tombol Shift, dan seluruh foto dari baris tersebut ke bawah akan terdorong turun 1 baris tanpa harus memasangkan ulang dari awal.

2. Pengelolaan Memori Browser (Object URL)

Masalah: Mengunggah folder berisi ratusan foto langsung ke browser bisa membuat lag jika file dirender langsung dari memori.

Solusi: Gunakan URL.createObjectURL(file) untuk preview foto di pool dan tabel. Ini jauh lebih ringan karena browser hanya membaca pointer filenya, bukan memuat seluruh blob gambar ke RAM. Panggil URL.revokeObjectURL() saat mengganti filter kelas untuk membersihkan RAM.

3. Navigasi Keyboard yang Responsif

Masalah: Penggunaan mouse terus-menerus untuk pilih foto lalu klik tabel masih terasa lambat.

Solusi: Buat keyboard shortcut focus state:

Arrow Left / Right: Memilih foto di panel atas.

Arrow Up / Down: Memilih baris siswa di tabel.

Space / Enter: Memasangkan foto terpilih ke baris siswa aktif, lalu otomatis memindahkan fokus ke baris siswa di bawahnya.

4. Penanganan Drag & Drop Folder di Browser

Masalah: Menggeser folder lokal ke browser membutuhkan penanganan khusus agar struktur filenya terbaca rapi.

Solusi: Gunakan HTML5 Drag and Drop API gabungan dengan webkitGetAsEntry() untuk membaca isi folder secara recursive, atau gunakan <input type="file" webkitdirectory> pada panel explorer kiri.

5. Auto-Save Draft (State Persistence)

Masalah: Jika tab browser tidak sengaja tertutup saat kamu baru selesai mencocokkan 80% data kelas A, semua progres akan hilang.

Solusi: Simpan state pencocokan sementara ke IndexedDB atau LocalStorage. Begitu halaman di-refresh, aplikasi bisa menawarkan "Lanjutkan pekerjaan Kelas A yang belum di-download?".
